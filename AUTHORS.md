# Attribution and citation

The CORE-SG method is credited to Antonio Cavalcante Araujo Neto, Murilo Coelho
Naldi, Ricardo J. G. B. Campello and Jorg Sander, ICDE 2022, pp. 951–964,
https://doi.org/10.1109/ICDE53745.2022.00076. These are scientific credits, not
a claim that those authors implemented this entire Python fork.

The Python project's existing metadata and copyright name the **Midas Core-SG
Team**. Git history records implementation contributions under Gabriel Orlando
and Gab0410, and integration contributions under Maylon Martins de Melo and
Maylon. People must confirm their aliases; commit counts are not author ranking.
Existing copyright and HDBSCAN third-party notices remain unchanged.

The `core-sg-mustache` fork includes Maylon's integration/reengineering and
reusable-support corrections. Its proposed software citation names the existing
team plus Maylon, separately from the method paper. This fork is not asserted
to be MIDAS's canonical release. Upstream: https://github.com/midas-core-sg/core-sg.
